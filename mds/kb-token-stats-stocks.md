# Knowledge-base token statistics: stocks

Measurements of the `stocks` source pages, a retrieval test of two chunk limits and an answer-quality test of the same
limits. The design these numbers feed into is [rag-data-design.md](rag-data-design.md); all categories side by side:
[kb-eval-summary.md](kb-eval-summary.md). Generated by `python -m scripts.kb_report --category stocks` from the
CSVs in [data/](data/); only the notes and findings are written by hand.

<!-- notes:start -->
**First measurement (2026-10-01):** 150 pages, the original 15 plus 135 added. How the 135 were chosen:
- From a curated list of core stock concepts: valuation ratios, corporate actions, trading and order mechanics,
  investing styles, technical and fundamental analysis, IPOs, regulation and fraud.
- Each page was checked to exist, not be a disambiguation page or stub (≥ 300 words), be finance-related, and not
  duplicate a page in any category.
- Companies, people, exchanges, indices and "List of…" pages were excluded. Candidates pulled from Wikipedia's own
  categories were weaker for beginners (e.g. court cases, country-specific tax schemes), so none were used.

Questions: q01–q30 were written from the pages and q31–q32 are out of scope. After the first retrieval run, q11, q17,
q20, q23 and q26 gained correct sections that other pages or sections also answer (e.g. the Stock page's own "Short
selling" section for q17).
<!-- notes:end -->

- **Sample:** the 150 `stocks` pages in [kb_topics.yaml](../src/data/kb_topics.yaml), full Wikipedia text (not
  truncated), saved in [tests/data/kb_snapshot/stocks/](../tests/data/kb_snapshot/stocks/).
- **Tokenizer:** `BAAI/bge-small-en-v1.5`, the embedding model, without `[CLS]`/`[SEP]`.
- **Raw vs clean:** "raw" is the text as `WikiClient.get_page()` returns it. "Clean" has each MathML formula dump collapsed
  to inline LaTeX; all section and paragraph figures use clean text.
- **Section** = text under one heading (`##`–`#####`), excluding its subsections. **Paragraph** = one line of the source
  text; list items count as separate paragraphs.

Data: [stocks_docs.csv](data/stocks_docs.csv), [stocks_sections.csv](data/stocks_sections.csv), [stocks_paragraphs.csv](data/stocks_paragraphs.csv).

## Reproduce

```bash
python -m scripts.kb_token_stats --category stocks --pages-dir tests/data/kb_snapshot/stocks
python -m scripts.eval_retrieval --category stocks      # builds the max512 / max250 test collections
python -m scripts.eval_generation --category stocks     # needs OPENAI_API_KEY
python -m scripts.kb_report --category stocks
```

## Generation test: answer quality

(the app's model, temperature 0) with the instruction to answer only from them (≤ 150 words) or say they don't cover
the question. `gpt-4o-mini` then judges the answer against the chunks and the question's `reference` / `key_points`.
Because the same model writes and judges, scores may be lenient.

| Metric | Scale | Meaning |
|---|---|---|
| Relevance | 1–5 | Does the answer address the question asked? |

| Correctness | 1–5 | Do the answer's facts agree with the reference answer? |
| Completeness | 0–1 | Share of the reference key points covered; 0 for a refused answerable question |
