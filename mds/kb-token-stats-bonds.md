# Knowledge-base token statistics: bonds

Measurements of the `bonds` source pages, a retrieval test of two chunk limits and an answer-quality test of the same
limits. The design these numbers feed into is [rag-data-design.md](rag-data-design.md); all categories side by side:
[kb-eval-summary.md](kb-eval-summary.md). Generated by `python -m scripts.kb_report --category bonds` from the
CSVs in [data/](data/); only the notes and findings are written by hand.

<!-- notes:start -->
**History:** first measured on 15 pages, now **50 pages** (2026-09-30); this replaces the earlier results.
Question set changes:
- **q21–q30** were added for the new pages.
- q08 (Clean price, Dirty price, Bond valuation), q14 (Government bond › Interest rate risk, Bond market › Volatility)
  and q16 (Zero-coupon bond) gained correct sections from the new pages.
- **q15** gained the Treasury page's savings-bond section after the first run showed it contains the same answer.
<!-- notes:end -->

- **Sample:** the 50 `bonds` pages in [kb_topics.yaml](../src/data/kb_topics.yaml), full Wikipedia text (not
  truncated), saved in [tests/data/kb_snapshot/bonds/](../tests/data/kb_snapshot/bonds/).
- **Tokenizer:** `BAAI/bge-small-en-v1.5`, the embedding model, without `[CLS]`/`[SEP]`.
- **Raw vs clean:** "raw" is the text as `WikiClient.get_page()` returns it. "Clean" has each MathML formula dump collapsed
  to inline LaTeX; all section and paragraph figures use clean text.
- **Section** = text under one heading (`##`–`#####`), excluding its subsections. **Paragraph** = one line of the source
  text; list items count as separate paragraphs.

Data: [bonds_docs.csv](data/bonds_docs.csv), [bonds_sections.csv](data/bonds_sections.csv), [bonds_paragraphs.csv](data/bonds_paragraphs.csv).

## Reproduce

```bash
python -m scripts.kb_token_stats --category bonds --pages-dir tests/data/kb_snapshot/bonds
python -m scripts.eval_retrieval --category bonds      # builds the max512 / max250 test collections
python -m scripts.eval_generation --category bonds     # needs OPENAI_API_KEY
python -m scripts.kb_report --category bonds
```

## Generation test: answer quality

`python -m scripts.eval_generation --category bonds`: for each question and limit, the top-5 chunks go to `gpt-4o-mini`
(the app's model, temperature 0) with the instruction to answer only from them (≤ 150 words) or say they don't cover
the question. `gpt-4o-mini` then judges the answer against the chunks and the question's `reference` / `key_points`.
Because the same model writes and judges, scores may be lenient.

| Metric | Scale | Meaning |
|---|---|---|
| Relevance | 1–5 | Does the answer address the question asked? |
| Faithfulness | 0–1 | Share of the answer's claims supported by the retrieved chunks (hallucination check); not scored for refusals |
| Correctness | 1–5 | Do the answer's facts agree with the reference answer? |
| Completeness | 0–1 | Share of the reference key points covered; 0 for a refused answerable question |

Refusals ("the sources don't cover this") are detected from the answer text. Raw results, with every answer, unsupported
claim and judge reason: [eval_bonds_generation.csv](data/eval_bonds_generation.csv), [eval_bonds_generation_summary.csv](data/eval_bonds_generation_summary.csv).
