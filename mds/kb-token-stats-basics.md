# Knowledge-base token statistics: basics

Measurements of the `basics` source pages, a retrieval test of two chunk limits and an answer-quality test of the same
limits. The design these numbers feed into is [rag-data-design.md](rag-data-design.md); all categories side by side:
[kb-eval-summary.md](kb-eval-summary.md). Generated by `python -m scripts.kb_report --category basics` from the
CSVs in [data/](data/); only the notes and findings are written by hand.

<!-- notes:start -->
**History:** first measured on 6 pages, then 15, now **50 pages** (2026-09-30); each run replaced the previous
results. Earlier versions are not kept in the repo. Question set changes along the way:
- **q21–q27** were added for the pages that took the category to 15, and **q28–q37** for the pages that took it to 50.
- Questions answered by newer pages gained those pages as extra correct sections:
  - q02 (APY page), q11 (Rule of 72), q13 (Purchasing power);
  - q03 (Future value), q08 (Present value), q15 (Consumer price index);
  - q22 (Real interest rate, Nominal interest rate), q33 (Money › Fiat).
- **q04's reference** was corrected after the first generation run. The question itself is unchanged.
<!-- notes:end -->

- **Sample:** the 50 `basics` pages in [kb_topics.yaml](../src/data/kb_topics.yaml), full Wikipedia text (not
  truncated), saved in [tests/data/kb_snapshot/basics/](../tests/data/kb_snapshot/basics/).
- **Tokenizer:** `BAAI/bge-small-en-v1.5`, the embedding model, without `[CLS]`/`[SEP]`.
- **Raw vs clean:** "raw" is the text as `WikiClient.get_page()` returns it. "Clean" has each MathML formula dump collapsed
  to inline LaTeX; all section and paragraph figures use clean text.
- **Section** = text under one heading (`##`–`#####`), excluding its subsections. **Paragraph** = one line of the source
  text; list items count as separate paragraphs.

Data: [basics_docs.csv](data/basics_docs.csv), [basics_sections.csv](data/basics_sections.csv), [basics_paragraphs.csv](data/basics_paragraphs.csv).

## Reproduce

```bash
python -m scripts.kb_token_stats --category basics --pages-dir tests/data/kb_snapshot/basics
python -m scripts.eval_retrieval --category basics      # builds the max512 / max250 test collections
python -m scripts.eval_generation --category basics     # needs OPENAI_API_KEY
python -m scripts.kb_report --category basics
```

## Generation test: answer quality

`python -m scripts.eval_generation --category basics`: for each question and limit, the top-5 chunks go to `gpt-4o-mini`
(the app's model, temperature 0) with the instruction to answer only from them (≤ 150 words) or say they don't cover
the question. `gpt-4o-mini` then judges the answer against the chunks and the question's `reference` / `key_points`.
Because the same model writes and judges, scores may be lenient.

| Metric | Scale | Meaning |
|---|---|---|
| Relevance | 1–5 | Does the answer address the question asked? |
| Faithfulness | 0–1 | Share of the answer's claims supported by the retrieved chunks (hallucination check); not scored for refusals |
| Correctness | 1–5 | Do the answer's facts agree with the reference answer? |
| Completeness | 0–1 | Share of the reference key points covered; 0 for a refused answerable question |

Refusals ("the sources don't cover this") are detected from the answer text. Raw results, with every answer, unsupported
claim and judge reason: [eval_basics_generation.csv](data/eval_basics_generation.csv), [eval_basics_generation_summary.csv](data/eval_basics_generation_summary.csv).
